# Школьный круг — код приложения

Учебный прототип для хакатона УрбанКод-2026 (кейс ГК «Ленстройтрест»). Все люди и данные выдуманы.

```bash
npm install     # один раз — скачать библиотеки
npm run dev     # запустить у себя
npm run build   # собрать готовый сайт в папку dist
```

Подробное описание — в `../README.md`.
