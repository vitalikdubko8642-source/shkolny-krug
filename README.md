# Школьный круг — код приложения

Учебный прототип для хакатона УрбанКод-2026 (кейс ГК «Ленстройтрест»). Все люди и данные выдуманы.

```bash
npm install     # один раз — скачать библиотеки
npm run dev     # запустить у себя
npm run build   # собрать готовый сайт в папку dist
```

Подробное описание — в `../README.md`.

## Важно о прототипе

Временная тестовая комната для жюри позволяет двум и более участникам переписываться между устройствами по коду с вымышленными никами. Остальные экраны — локальная демонстрация: реальных регистраций, синхронизации обычных чатов, отправки жалоб администрации и уведомлений родителям нет. Код учителя `OKLA2026` только демонстрирует сценарий и виден в исходном коде: он не защищает реальный аккаунт. Срочные сообщения не вызывают помощь. В конкурсной проверке не использовать реальные личные данные.

Сервер ИИ в `worker/` использует Cloudflare Workers AI. Тексты отправляются только после явного подтверждения и должны быть вымышленными. CORS ограничивает браузерные запросы адресом опубликованного сайта; ограничение запросов приблизительное и не заменяет авторизацию. На localhost запросы к серверу ИИ намеренно не разрешены. В случае ошибки интерфейс показывает недоступность сервиса.

Для проверки логики запустите `node tests/worker.mjs` и `node tests/meeting.mjs`. Браузерные сценарии `tests/*.cjs` требуют `playwright-core`, Edge и запущенный `npm run dev -- --host 127.0.0.1 --port 5190`.
